## About Velocity Executor

Velocity Executor is a Windows desktop application for running Lua-based Roblox scripts and accessing scripts through a built-in hub. Its local interface brings script loading, organization, and execution tools together in a single workspace.

The application is intended for fast execution, queue management, and workflows that can accommodate updates over time. It also provides batch-oriented controls, an integrated script hub, and an offline desktop layout for Windows users.

## Feature Highlights

- Start Lua scripts quickly with one-click execution
- Browse and launch content from a built-in hub containing 500+ scripts
- Keep several scripts ready through a persistent execution queue
- Use the auto-update engine to help maintain a current installation
- Switch among supported interface languages
- Run grouped actions in order with batch execution
- Inspect script behavior using the included debugger
- Work through a locally installed Windows desktop interface without requiring an online app layout
